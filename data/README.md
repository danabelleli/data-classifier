# Reference data

Every list in this folder comes from an official US source. None of it was typed by hand or generated by AI.
The raw downloads are turned into these files by [`scripts/build_reference_data.py`](../scripts/build_reference_data.py). Anyone can re-download the sources and re-run the script to check the files.

| File | Source | Source URL | Downloaded | What the script does |
|---|---|---|---|---|
| `area_codes.csv` | NANPA (North American Numbering Plan Administrator), NPA report | https://reports.nanpa.com/public/npa_report.csv (linked from https://www.nanpa.com/reports/npa-reports) | 2026-11-13 (report dated 11/13/2026) | Keeps area codes that are in service and either US geographic (`COUNTRY = US`, includes territories like Puerto Rico) or toll-free (800, 833, 844, 855, 866, 877, 888). Region = state name, or "Toll-free". Canada and Caribbean countries also use +1 and are left out (the app is US only). |
| `us_places.csv` | US Census Bureau, 2010 Gazetteer Files, Places | https://www2.census.gov/geo/docs/maps-data/data/gazetteer/Gaz_places_national.zip | 2026-11-13 | Keeps name, state code and population (`POP10`) for the 50 states + DC. Strips the place-type suffix ("Austin city" → "Austin", "Honolulu CDP" → "Honolulu"). For city-county governments (for example "Nashville-Davidson metropolitan government (balance)") it also adds the short name ("Nashville"). |
| `us_states.csv` | US Census Bureau, state FIPS codes | https://www2.census.gov/geo/docs/reference/state.txt | 2026-11-13 | Keeps the 50 states + DC (codes ≤ 56): full name and 2-letter abbreviation. |
| `surnames.txt` | US Census Bureau, 2010 surnames | https://www2.census.gov/topics/genealogy/2010surnames/names.zip | 2026-11-13 | Lowercases every surname, drops the "ALL OTHER NAMES" summary row. 162,253 names. |
| `first_names.txt` | Social Security Administration, baby names, national data | https://www.ssa.gov/oact/babynames/names.zip | 2026-11-13 (downloaded in a browser; the SSA site blocks scripted downloads) | Merges all years (`yob1880.txt` … `yob2025.txt`, 146 files), deduplicates and lowercases. 105,966 names. |
| `country_codes.csv` | ITU (International Telecommunication Union), "List of ITU-T Recommendation E.164 assigned country codes", position on 15 December 2016 (Annex to ITU Operational Bulletin No. 1114), the latest edition listed on the ITU publication page | https://www.itu.int/dms_pub/itu-t/opb/sp/T-SP-E.164D-2016-PDF-E.pdf (listed on https://www.itu.int/pub/T-SP-E.164D) | 2026-11-13 | The source is a PDF. Its text was extracted and saved as `itu_e164_country_codes.txt`; the script reads the numerical-order list, keeps every assigned code (countries and global services like +800 and +881), skips "Spare code" and "Reserved" entries, and removes footnote letters from the names. Codes shared by several places (+1, +7, +39…) list all of them. 217 codes. Changes after December 2016 are published as amendments in the ITU Operational Bulletin and are not included. |

## Why the 2010 Gazetteer

The spec asks for place population (cities with 10,000+ people are recognized without a state column). The 2010 Places Gazetteer is the latest edition that includes a population column; the 2020-and-later editions only have land area and coordinates. City names change slowly, so the 2010 list still covers the cities people write. The known gap is places that grew past 10,000 after 2010: they still match when the file has a state column.

## Rebuilding

```bash
# 1. Download the sources above into one folder, for example ~/raw:
#    npa_report.csv, state.txt, Gaz_places_national.txt (unzipped),
#    Names_2010Census.csv (unzipped), and the SSA zip unzipped into ~/raw/ssa_names/
# 2. Run from the project root:
python3 scripts/build_reference_data.py ~/raw
```
